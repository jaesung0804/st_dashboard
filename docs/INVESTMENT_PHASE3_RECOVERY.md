각 대조는 별도 자금·체결 재생으로 계산한다. 엔진의 회사/종목별 거래량 한도는 팀 간 공유되므로, 과거 팀별 NAV를 이어 붙여 두 팀 지원안을 만들어서는 안 된다. 신호 후 체결, 거래 불가 보유분, 미체결 주문, 비용, 현금, 불리한 결과를 모두 유지한다. 기존 2023~2026 관측자료의 재생은 탐색 분석이며, 새로운 독립 표본이나 AI 액티브 실적이 아니다.

완료 전 필수 확인: 원본 해시, 동일 정책·35명 명부, 모든 9개 대조 보존, 비용·지연별 벤치마크, 실제 체결원장, 작성자와 분리된 심사. 기업 KPI 가설의 검증 ID는 이 배정 대조와 별도로 둔다.

## 비용·보존 제약

`investment-phase3-recovery.yml`은 해당 공개 저장소의 표준 Ubuntu 실행기에서 읽기 전용으로만 작동한다. 상태 조회 5분·대조 실행 15분 제한, 캐시·Actions artifact 업로드 없음. 공개 저장소 표준 실행기는 무료이며 큰 실행기는 과금 대상이다. [GitHub Actions 과금 기준](https://docs.github.com/en/billing/concepts/product-billing/github-actions)

Oracle Always Free Autonomous DB의 저장 한도는 20GB이며 무료 상태에서 자동 확장되지 않는다. 한도 초과 시 오래된 기록이 안전하게 순서대로 지워지는 보호장치로 가정하지 않는다. OCI Object Storage는 DB와 별도 용량이고, 체험 종료 시 무료 저장량 초과는 객체 전체 삭제 위험을 포함한다. [Oracle 무료 DB](https://docs.oracle.com/en/cloud/paas/autonomous-database/serverless/adbsb/autonomous-always-free.html), [Oracle Always Free 저장소](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm)

이번 복구는 DB/OCI 쓰기를 차단한다. 20GB를 채워서 자동 폐기에 의존하지 않는다. 향후 저장 재개 전 실제 DB·OCI 사용량과 무료 상태를 확인하고, 핵심 명부·정책·결정·미완료 체크포인트 및 원본 해시를 보존해야 한다. 새 파일 총 2MB·단일 500KB 목표를 유지하며, 대용량 원본의 중복 업로드와 전체 재이관을 실행하지 않는다.
