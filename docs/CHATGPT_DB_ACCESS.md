# 웹 ChatGPT에서 투자 DB 사용

확인일: 2026-09-13. **해결 가능한 연결 문제**입니다. DB가 Codex 전용인 것은 아닙니다. 현재 Oracle/OCI 백엔드는 별도 HTTPS API로 동작하며, 이번 점검에서 연결 상태·데이터 목록·한국과 미국 최신 월의 한 행 조회가 성공했습니다.

## 현재 연결 범위

| 사용 환경 | 현재 상태 |
|---|---|
| GitHub Actions | 저장소의 비공개 token과 URL 설정으로 기존 API 사용 |
| 이 PC | 이전 구축 작업의 비공개 설정과 Python 도우미로 조회 가능 |
| 웹 ChatGPT 일반 대화 | 프로젝트 대화만으로 PC의 실행 환경·token·DB 도구가 전달되지는 않음 |
| 홈페이지 | 공개 HTML/JSON 결과 조회. DB 인증용 창구가 아님 |

저장소에는 `scripts/research_backend_client.py`, `backend_records.py`, `backend_references.py`, `backend_rows.py`가 있습니다. 별도로 배포된 서버는 FastAPI REST 서비스입니다. 확인한 서버 소스에는 MCP 도구 전송 경로가 없습니다. API 주소를 프로젝트 지침에 적는 것만으로 호출 도구가 생기지는 않습니다.

## 연결 제안

`웹 ChatGPT → 인증된 MCP 연결 → 기존 투자 API → Oracle DB / OCI 파일 저장소`

기존 API를 호출하는 얇은 MCP 서비스를 추가하는 방식이 적합합니다. DB를 새로 만들거나 원자료 전체를 ChatGPT에 업로드할 필요는 없습니다. OpenAI는 ChatGPT에 MCP 서버를 등록하고 대화의 도구 메뉴에서 사용하는 절차를 제공합니다. 공개 HTTPS 또는 Secure MCP Tunnel을 사용할 수 있으며, 개발자 모드 제공 여부는 계정·워크스페이스 정책에 따라 다릅니다. [공식 연결 문서](https://developers.openai.com/plugins/deploy/connect-chatgpt)

첫 연결은 다음 조회만 제공하면 됩니다.

- 연결 상태와 데이터별 기준일 확인
- 종목·월·날짜 범위를 지정한 주가 조회
- 연구·업무 기록 목록 20개와 선택한 기록 한 개 조회
- 필요한 스냅샷의 메타데이터·출처 해시 확인

투자 프로젝트를 서버에서 고정하고, 필요한 조회 API만 도구로 노출합니다. 초기 연결에는 읽기 전용 권한을 부여하는 설계가 필요합니다. 현재 프로젝트 token을 대화·Git·공개 JavaScript에 복사하지 않습니다. 추후 기록 쓰기를 추가하면 기존 `expected_version` 검사와 HTTP 409 처리, 여러 참조의 원자 저장을 그대로 사용합니다.

구현 후에는 인증·프로젝트 범위·조회 제한을 확인하고 ChatGPT에서 실제 도구 호출을 검증해야 합니다. 서버를 등록하는 것과 각 대화에서 연결이 활성화되는 것은 각각 확인합니다. 이 문서는 연결 방안이며, 이번 폴더 점검에서 MCP 배포나 웹 계정 등록까지 수행한 것은 아닙니다.

## 연결 전 사용 방법

웹에서는 공개 대시보드나 날짜·출처가 붙은 작은 조회 결과로 분석할 수 있습니다. 파일을 첨부한 방식은 그 시점의 스냅샷이고, 이후 DB 변경이 자동 반영되지 않습니다. 최신 원자료 조회가 필요하면 현재 연결된 PC 도우미 또는 기존 GitHub 실행 환경을 사용합니다.

DB 연결과 모델 실행 방식도 구분해야 합니다. 현재 운영 배치는 검증된 CSV·모델 스냅샷을 복원해 계산하며, 모든 모델 계산이 SQL 기반으로 바뀐 것은 아닙니다. SQL 게시량과 미완료 연구 상태는 [이번 점검 기록](PROJECT_AUDIT_20260913.md)을 참고합니다.
