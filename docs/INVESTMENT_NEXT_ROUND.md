# 다음 회차 연구안 · 아직 실행하지 않음

이 문서는 r03 결과를 본 뒤 작성한 후속 연구안이다. 이미 관찰한 2006–2026년 결과를 다시 사용하면 탐색 연구로 표시한다. 자료를 여러 구간으로 나누거나 회차 이름을 바꾸어도 미사용 검증이 되지 않는다. 새 1시간 회차나 매일 운용 작업을 예약하지 않았다.

다음 비교의 후보 배정은 `data/reference/investment_next_round_proposal.json`에 고정했다. 효율 고정, 위 두 팀만 70/30, 모든 팀 70/30의 세 배정안을 비교한다. 회사마다 같은 초기 자금, 수수료와 체결 지연을 적용하고, 직원별 승인 요청에는 자신의 투자 논리·진입·철회·주기·위험·근거 기준일을 남긴다. 배정안은 연구 후보이며 실제 운용 변경이 아니다.

## 기업 논리를 실제 검증으로 잇는 순서

NOW는 계약과 구독 현금의 연결, QCOM은 QCT/QTL 및 최종시장별 매출·마진, NBIX는 제품별 매출과 인수 이후 현금 부담을 공시 날짜별로 정리한다. 먼저 각 수치의 원문 위치·단위·기간·접수 시각을 보존하고, 누락값은 추정해 채우지 않는다. 오늘 작성한 논리를 과거 당시에 작성된 논리로 표시하지 않는다.

각 기업·기간 가설에 규칙 버전, 사용할 KPI, 매수·철회 조건, 판정 시점, 사용할 데이터의 당시 가용 시점을 연결한다. 이 명세와 자료가 준비되기 전까지 가설은 실행 불가다. 실제 그 규칙을 계산한 실험만 해당 가설의 검증 이력에 연결하며 일반 재무·가격 전략 결과를 기업 고유 논리의 성과로 옮겨 붙이지 않는다.

## 검증과 인사

현재 표본의 생존 편향과 상장폐지 회수 자료 부족은 별도 미해결 과제로 유지한다. 새 관찰 검증은 이 연구안 등록 뒤 처음 알게 되는 시장 자료부터 시작해야 하며, 같은 자금·현금 비중의 SPY 대조군도 함께 기록한다. 과거 탐색 성과와 새 관찰 성과는 원장을 분리한다. 장기 전략은 실제 보유 주기와 충분한 관찰을 채우기 전까지 성과 검증 완료로 표시하지 않는다.

각 실제 60분 회차 안에서는 직원 명단과 전략 버전을 고정한다. 위험에 따른 운용 중단·배정 축소는 퇴사가 아니다. 회차 종료 후 비용 포함 성과, 낙폭, 조건별 일관성, 관찰 길이, 실패 근거를 함께 검토한다. 매번 반드시 누군가를 해고·채용하지 않으며 한 회차의 최고 수익만으로 승진시키지 않는다.

운영조정팀은 자료·심사·배포 의존 관계를 관리한다. 투자 또는 인사 권한을 대신 행사하지 않는다. Trello에 주요 요청과 결정을 계속 기록하고 이 대화에는 카드별 업로드 결과를 반복 표시하지 않는다. 신규 유료 서비스, LLM API, 실주문, Telegram 전송은 이 연구안에 포함하지 않았다.
