# 2차 실행 중 수정 기록

2026-09-10 첫 2차 실행은 장기 성과배분 팀의 예산이 0이 된 구간에서 NAV 수익률을 계산하다가 중단됐다. JSON에 NaN이 들어가는 것을 허용하지 않는 검사가 게시를 차단했다.

전액 환매된 팀의 달러 잔고를 전일 잔고로 나눈 수익률은 정의되지 않으며, 입출금을 운용실력으로 섞는다. 팀 성과는 입출금 때 발행·환매되는 펀드 단위의 순자산가로 계산하도록 고쳤다. 회사 전체 성과는 모든 팀과 본사 현금의 합계로 계속 계산한다. 매수·매도·순위·비용·배분 규칙과 고정한 실험 목록은 변경하지 않았다.

중단된 원장은 작업용 보관 영역에 보존하며 성공 결과로 게시하지 않는다. 2차 정식 디렉터리는 수정한 집계 코드로 전체 18개 실험을 다시 실행해 완성한다.
