# 주식 조기경보 대시보드 사용법

사이트의 한국/미국 화면에서 종목명 또는 티커를 검색한다. 검색은 관심 후보 필터와 관계없이 선택 신호일의 전체 보관 종목을 대상으로 한다. 검색을 지우면 선택한 보기 조건이 다시 적용된다. 종목명을 누르면 해당 신호일의 상세 화면으로 이동한다.

## 화면에서 읽는 순서

1. **신호일**을 확인한다. 장중 실시간 정보가 아니라 완료된 종가와 저장된 예측이다.
2. **과거 6개월 수익률**로 이미 일어난 가격 변화를 확인한다. 시작일과 종료일은 상세에 표시한다.
3. **6개월 상승 기회**와 **3개월 급락 위험**을 각각 읽는다. 두 사건은 동시에 발생할 수 있다.
4. **후보 판정**에서 기준을 통과했는지, 어떤 조건이 부족한지 확인한다.
5. 상세의 **관측 지표**, **모델·예측 생성 기록**에서 수치의 의미, 사용 모델 월, 생성 유형을 확인한다.

| 표시 | 의미 | 의미하지 않는 것 |
|---|---|---|
| 6개월 상승 기회 30% | 126개 가격 관측 뒤 조정 종가 수익률 +20% 이상이고 신호일 유동성 통과 종목의 중간 수익률보다 +10%p 이상인 사건의 추정 확률 | 예상 수익률 +30%, 무조건 오를 확률, 확정 승률 |
| 3개월 급락 위험 25% | 이후 63개 관측 안에 조정 종가가 신호 종가보다 20% 이상 낮아지는 사건의 추정 확률 | 예상 손실 −25%, 장중 저가, 이후 고점 대비 최대 낙폭 |
| 과거 6개월 수익률 +15% | 선택일 조정 종가 / 126개 관측 전 조정 종가 − 1 | 미래 예상 수익률, 배당·비용·체결을 모두 반영한 투자 성과 |
| 평가 없음 | 해당 신호일의 저장된 모델 점수가 없음 | 위험 0%, 수익 기회 0%, 반드시 나쁜 종목 |

확률이 올바르게 보정되어 있다면 비슷한 30% 추정 사례들의 사건 발생률은 약 30%여야 한다. 실제로 그렇게 맞는지는 이후 자료에서 검증해야 한다. [확률 보정의 의미](https://scikit-learn.org/stable/modules/calibration.html).

## 한국 2026-09-04에 관심 후보가 없었던 이유

저장된 새 모델 평가 1,079개 중 상승 기회 20% 이상은 980개였다. 관심 후보는 여기에 **보정 전후 하락 추정 중 높은 값이 15% 미만**이어야 한다. 그날의 최소 상단은 22.55%였으므로 최종 후보는 0개였다. 시장 전체가 반드시 급락한다는 결론은 아니다. 모델 추정 분포와 보수적인 표시 기준의 결과다.

예를 들어 삼성전자(005930)의 저장된 값은 상승 기회 35.33%, 급락 위험 59.55%, 하락 추정 범위 32.31–59.55%다. 상승 조건은 통과하지만 하락 위험 조건을 통과하지 못했다. 이 숫자는 각각 다른 사건의 추정 확률이다.

새 화면은 기본으로 모델 추천 종목을 표시한다. 검색어를 입력하면 후보 필터와 관계없이 전체 보관 종목에서 찾는다. 모델 평가가 없어도 보관 목록에서 검색할 수 있으며, 확인 가능한 가격·거래량·이력 조건을 설명한다. 최신 보관 목록을 사용하므로 과거 날짜의 완전한 상장 구성을 재현하는 기능은 아니다. 2026-09-04 자료 기준 검색 대상은 한국 2,650개, 미국 5,020개다.

## 월 학습·일 추론으로 바뀐 점

- 전월 말까지의 데이터로 월 1회 모델을 학습하고 고정한다. 일 배치는 고정된 모델로 새 신호일을 추론한다.
- 같은 날짜의 예측은 재실행해도 덮어쓰지 않는다. 월이 바뀌어 새 모델을 만들어도 이전 기록은 유지한다.
- 시장별 로지스틱 회귀와 작은 LightGBM의 추정을 50:50으로 결합한다. 가격 추세·거래량·변동성·상대강도·시장 폭 등 25개 입력을 사용한다.
- 미래 결과가 끝까지 관측된 표본만 학습하며, 학습과 확률 보정 구간을 시간 순서로 나눈다. 미래 결과 구간이 경계에서 겹치는 표본을 제외하고, 전처리도 학습 자료에만 맞춘다.
- 보정에 사용한 자료의 진단값과 독립 시험 성능을 구분한다. 개발 과정에서 참고한 과거 검증은 앞으로의 실전 수익을 보장하지 않는다.

현재 운영 모델은 가격·거래량 기반이다. 보관 중인 재무자료나 거시경제 API 자료를 입력으로 사용하지 않는다. 기본 평가 조건은 253개 가격 관측, 당일 거래량, 20일 평균 거래대금 한국 5억원/미국 500만 달러 이상, 종가 한국 1,000원/미국 1달러 이상이다.

## 별도 거시 실험과 검증 페이지

상단 **모델 설명·검증**으로 이동하면 사용법, 가격·거시 검증, 실험 종목 조회를 나눠 볼 수 있다. 추천·종목 상세 화면에는 긴 설명이 이어지지 않는다. 보정 자료의 진단값, 시간 분리 시험, 앞으로 저장될 실전 결과를 구분한다.

강화한 실험 상승 목표는 126번째 시장 거래일까지의 마지막 5거래일 평균 조정 종가가 신호 종가보다 **25% 이상**, 신호일 전체 관측 종목의 같은 기간 평균보다 **15%p 이상** 높은 것이다. 마지막 5일 중 4일 이상도 이 절대·초과 기준을 모두 충족해야 한다. 마지막 5일에는 실제 거래량이 있어야 하며, 정지된 시세를 지속 상승으로 판정하지 않는다. 전체 평균이 +20%라면 최소 +35%가 필요하다. 미래 가격을 관측할 수 있는 비중이 95% 미만인 날짜와 결과가 없는 종목은 정답을 만들지 않는다.

동일한 강화 목표·학습 표본을 사용하는 가격 모델과 가격+거시 모델을 비교한다. 운영 모델의 기존 목표와 다르므로 새 확률과 운영 확률을 직접 비교하지 않는다. 현재 운영 모델은 유지하고 별도 모델·예측을 월별·일별로 고정 저장한다.

거시 입력은 FRED-MD의 월별 원본에 당시 실려 있던 정책금리, 미국 10년−3개월 금리차, 물가 상승률과 3개월 변화, 실업률과 3개월 변화, 산업생산·고용·주택착공·통화량의 전년 대비 변화다. 미국 거시경제와 글로벌 금리 환경이며 한국 국내 거시 전체를 뜻하지 않는다. 2026-07 빈티지를 2026-09-02부터 쓰는 식으로 추가 지연을 적용한다. 개별 발표 시각을 정확히 재현하는 대신, 보관 월의 두 달 뒤 1일보다 뒤인 신호일에만 반영한다.

과거 시험 월은 2024-10, 2025-04, 2025-10, 2026-02다. 시험 월 시작 전에 결과가 완전히 관측된 자료만 학습·보정하며 경계의 중첩 결과를 제거한다. 같은 신호일의 종목 수가 많다고 거시 정보의 독립 표본이 늘어나는 것은 아니므로 학습 가중치는 신호일마다 총합이 같다. 전체 시험의 AUC/Brier와 월별 결과를 모두 공개한다. 보정 기울기가 음수면 순위를 뒤집지 않고 원래 추정을 유지하며 화면에 표시한다.

검증의 6개월 실현 수익률은 신호일별 상승 확률 상위 10%의 5일 평균 가격 수익률을 날짜별 같은 비중으로 평균한 값이다. 실제 포트폴리오·배당·비용·수익률 복리를 계산한 값이 아니다. 보관 데이터의 생존 편향, 상장폐지 누락, 과거 가격 정정과 6개월 결과 구간 중첩은 여전히 남는다. 실험 모델의 도입 효과는 앞으로 저장될 독립 결과에서도 확인해야 한다.

`Macro EWS comparison`은 매월 1일 04:45 UTC에 별도 학습하며, `Daily Refresh` 성공 뒤에는 고정 모델로만 추론한다. 월 모델이 아직 없으면 일 배치가 학습을 대신하지 않고 월 학습 대기를 로그에 남긴다. 이번 최초 도입과 명시적 수동 `train` 실행에서만 월 모델을 초기화할 수 있고, 이미 존재하는 같은 월 모델·예측은 덮어쓰지 않는다. 상태는 `data/dashboard_ews_shadow`에 분리되며 기존 상태 압축·저장·Pages 검증 경로에 함께 보존한다.

초기 데이터는 2026-09-06 공식 원본에서 수집한 79개월의 파생 입력 약 74 KB를 체크섬과 함께 보관한다. GitHub 실행 환경에서 큰 과거 압축 파일 요청이 시간 초과되어 재현 가능한 초기 자료를 추가했다. 이후에는 빠진 새 월 CSV만 내려받고, 이전 캐시의 체크섬부터 확인한다. 초기 자료가 있다는 이유로 미래 월 자료 수집 실패를 성공 처리하지 않는다.

첫 2026-09-04 기록은 모델이 만들어진 9월 6일에 생성된 **지연 기록**이다. 당시 매매 가능한 실시간 예측 성과로 해석하면 안 된다. 이전 버전의 순위 점수도 새 사건 확률과 직접 비교하지 않는다. 자세한 운영·검증 계약은 [월 학습 모델 문서](monthly-ews.md)를 참고한다.

## 앞으로 6개월의 수익률은?

현재 모델은 조건을 만족할 사건 확률을 계산한다. 상승 확률에 20%를 곱해 기대수익률을 계산할 수 없다. 조건을 만족하지 않았을 때의 손실 크기와 만족했을 때의 상승 폭에 대한 분포가 없기 때문이다.

이번 화면에서 추가한 숫자는 **과거** 126개 가격 관측 구간의 변화다. 선택일 이후 가격을 사용하지 않는다. 해당일 가격이 없거나 126개 구간이 부족하거나 구간 내 조정 가격이 결측이면 수익률을 표시하지 않는다. 같은 보관 가격 버전으로 구간 전체를 계산하며 데이터 파일의 체크섬도 남긴다. 원천 제공자의 소급 정정에 따라 가격 설명 값은 바뀔 수 있지만 예측 기록의 확률은 바뀌지 않는다.

새 실전 예측이 126개 구간을 채운 뒤의 실현 수익률은 별도 평가 대상이다. 이를 기다리지 않고 과거 사례로 평균 기대수익률을 표시하려면 별도의 시간 분리 검증과 표본 수·분포·비용 조건이 필요하다. 현재 화면은 검증되지 않은 목표 주가나 미래 수익률을 만들어 표시하지 않는다.

## 이번 화면 변경의 범위와 검증

`price_context/YYYY-MM-DD.json`은 표시용 보관 시세·과거 수익률·검색 목록이다. 기존 모델 파일과 예측 JSON에는 필드를 추가하지 않는다. 전체 종목은 페이지로 나누어 표시하며 일부 상위 종목만 잘라서 검색하는 방식이 아니다.

UI 변경은 저장 상태를 읽어 화면만 다시 만든다. 재학습·재추론·상태 push를 하지 않는다. 공개 전 예측 JSON의 바이트 일치를 검사하고, Pages 빌드 뒤 공개 manifest·HTML·CSS·JavaScript·최신 가격 설명 파일의 체크섬을 확인한다.
