# 투자회사 실험 v1

목표는 기존 자료로 수년의 모의운용을 빠르게 재생하고, 그 기록을 실제 미래의 연구·모의운용으로 연결하는 것이다. 이 실험은 배포 중인 대시보드와 독립적이며 기존 예측이나 원가격을 변경하지 않는다.

## 이번에 구현한 범위

- 펄스·컴파운드·어댑티브 3회사, 회사당 3개 규칙 기반 운용팀.
- 시장별 회사 초기자금: 한국 1억 원, 미국 10만 달러. 국가별 독립 실험이므로 환율을 가정해 수익률을 합산하지 않는다.
- 각 팀 30%·본사 현금 10%. 기간별 재검토 주기 1/5/21/63/126/252거래일. 실제 보유기간은 다음 결정까지이며 1일팀도 같은 종목을 연속 보유할 수 있다.
- 공시 접수 다음 날 이후의 재무 지표와 과거 가격만 입력. 과거 LLM 대화를 새로 생성하지 않는다.
- 현재 3단계 산업분류 원장에는 확인 시각과 분류 출처를 붙인다. 이는 현시점 애널리스트 검토 초안이며 과거 재생에는 사용하지 않는다.
- 회사 간 자료 요청, 감사와 후속 실험을 트렐로에 기록한다. 이 카드는 실제 수행된 작업과 남은 요청이며 상시 실행되는 별도 모델을 뜻하지 않는다.

## 실행

기존 `dashboard-state`의 원가격 두 파일과 `data/reference/accounting_cohort.json`의 표본을 사용한다. 가격 상태 스냅샷 SHA는 첫 실행의 입력 파일 해시로 고정했다. 재무는 저장소에 포함된 접수일 스냅샷으로 복원할 수 있다.

```bash
python scripts/restore_accounting_seed.py
PYTHONPATH=src python tests/test_investment_replay.py
python scripts/run_investment_replay.py --out docs/replays/new-run-id
```

가격 파일이 로컬에 없다면 `dashboard-state`를 별도 체크아웃하고 `scripts/unpack_dashboard_state.py`의 `restore_split`에 `state-manifest.json`의 해당 파일 항목을 넘겨 복원한다. 전체 연구 상태를 복원할 필요는 없다. 기존 파일을 해시 검증 없이 대체하지 않는다.

```bash
python scripts/build_research_sector_registry.py --state-dir ../st_state \
  --observed-at 2026-09-10 --out data/reference/research_sectors_20260910.csv.gz
```

실행에는 이미 설치된 Python·NumPy·pandas를 사용한다. 산업분류 원본 Excel을 읽는 경우 openpyxl도 필요하다. 유료 API, 유료 데이터 조회, 새로운 클라우드 작업, 스케줄이나 텔레그램 발송을 호출하지 않는다. 사용 중인 ChatGPT 구독 자체의 포함 사용량은 소비된다.

## 체결·평가 원칙

신호일 종가로 주문 수량을 동결하고 다음 관측 거래일 시가에서 체결한다. 매도 후 매수하며 현금을 초과하면 매수량을 줄인다. 전일 거래량 1% 한도를 사용하고, 가격 누락·한도 초과 미체결 잔량은 그날 만료한다. 오늘 종가·거래량으로 오늘 시가 주문을 유리하게 정하지 않는다.

모든 가격은 보존된 조정 가격 단위로 환산하며 소수 수량을 허용한다. 이는 실제 주식 수량·정수 주문을 정밀하게 재현하는 체결기가 아니다. 한국 현금배당, 미국 원천세, 가격 제한 잠김, 정수 주식, FX, 상장폐지 정산은 미완성이다. 편도 한국 25bp·미국 10bp는 모든 거래비용의 단순 연구 가정이고 2배 비용을 함께 비교한다.

종목당 10%는 재검토 때의 **목표 비중 한도**다. 이후 가격 변화로 비중이 커질 수 있으며 일중 강제 한도라고 부르지 않는다. 다음 버전은 사전 고정된 집중도 축소 규칙을 별도 비교한다. 섹터 한도는 당시 분류가 없어 이 재생에서 사용하지 않는다.

보유종목의 가격이 없어도 그 종목과 손익을 제거하거나 남은 종목 비중을 다시 정규화하지 않는다. 마지막 관측가를 유지하되 5거래일 이상 누락되면 결과를 미확정으로 표시한다. 이 표시가 있는 전략은 승자로 선정하지 않는다. 별도 표본 동일가중·단순 모멘텀 비교군은 공식 시장지수가 아니다.

## 조직 운영과 버전

첫 실험에서 자금 배분과 규칙을 고정한 이유는 전략 성과와 인사·배분 효과를 구분하기 위해서다. 뒤의 자금 재배분 실험은 같은 고정배분 회사와 비교하고, 판단시점에 이미 종료된 성과만 평가한다. 계열 팀의 상관이 높은 손익을 독립적인 성공 사례 여러 개로 세지 않는다. 회사별 자금 재배분과 그에 따른 거래비용을 함께 기록한다.

서술형 논리 카드에는 `hypothesis_id`, `created_at`, `as_of`, `sources`, `sector_l1/l2/l3`, `horizon`, `claim`, `counterargument`, `entry_rule`, `invalidation_rule`, `review_at`, `decision`, `policy_version`, `status`를 둔다. 자료 부족은 관망이며 가상의 출처를 채우지 않는다. 회사들은 공통 자료를 공유하되 서로의 현재 주문은 각 결정을 고정한 뒤 비교한다.

1년 팀의 승진은 몇 주의 수익률로 판단하지 않는다. 분기별로 규칙 준수·비용·낙폭·근거 품질을 검토하고, 충분히 성숙한 투자 사례가 없으면 자금 비중을 유지한다. 보상은 가상 권한·가상 운용금액이며 실제 모델 학습이나 임금 지급이 아니다. 퇴출한 전략도 원장에 보존한다.

## 일일 운영과 텔레그램

이번 실행에서는 시작하지 않는다. 사용자가 요청한 순서는 과거 재생으로 구조 정립 → 실제 날짜별 모의운용 → 중요 투자방법 제안이다. 실제 운영은 새 데이터 도착 확인, 일일 원장 복원, 중복 주문 방지, 최신성 표시, 실패 시 신규 판단 보류를 갖춰야 한다.

일일 제안에는 시장·기간, 행동(관망/분할진입/비중조절/논리철회), 근거, 반증조건, 이전 의견과 달라진 점을 담는다. TaskNotify가 제공하는 무료 범위 및 연결된 본인 수신처를 확인한 뒤 발송하며 유료 전환·크레딧 구매·API 키 발급을 자동으로 시도하지 않는다. 발송 실패는 재발송 폭주 없이 기록한다.
